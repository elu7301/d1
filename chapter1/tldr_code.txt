КРАТКО О КОДЕ ПЕРВОЙ ГЛАВЫ
ВКР Королева Дмитрия Геннадиевича

Назначение: проверяемый пример анализа розничных продаж и сравнения прогнозов
для первой главы ВКР о сценарном планировании.

Данные: реальные продажи Walmart M5, магазин CA_1, три товара.
Период 29.01.2011–22.05.2016; 5823 наблюдения «товар — день».
Источник и преобразования описаны в data/README.md.

Что реализовано:
- Проверка CSV: даты, числовые значения, дубликаты, полный дневной календарь.
- Статистика продаж по товарам и дням недели, просмотр графиков.
- Три прогноза: среднее последних 7 дней, повторение последней недели,
  линейная Ridge-регрессия, реализованная через NumPy.
- Оценка MAE, RMSE, WAPE и смещения на последних 28 днях.

Проверка: обучение до 24.04.2016, прогноз на 25.04–22.05.2016.
Будущие фактические продажи и цены в модель не подставляются.
Цена фиксируется на последнем уровне обучения; календарь считается известным.
Общая WAPE: Ridge — 18,90%; повторение недели — 25,06%; среднее — 26,53%.
Результат относится к трём товарам и одной точке начала прогноза.

Основные файлы: chapter1/main.py — порядок работы; common/data.py — проверка;
chapter1/analysis.py — анализ; chapter1/forecast.py — модели;
common/metrics.py — ошибки. common/main.py объединяет главы.

Запуск из корня проекта: python main.py
Графики: python main.py --plots
Проверки: python -m unittest discover -s chapter1 -v
Нужен Python 3.12 или новее и библиотеки из requirements.txt.

Шесть проверок прошли. Генерации данных и автоматической записи результатов
в файлы нет. Прогнозируются наблюдаемые продажи. Остатки, прибыль, сценарии
поставок и интерфейс будут реализованы в следующих главах.
