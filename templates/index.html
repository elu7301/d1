Будущий календарь — необязательно

По одной строке на каждый будущий день. Без календаря будущие SNAP и события принимаются равными 0.

Будущая цена фиксируется на последнем известном значении. Допущения сохраняются вместе с исследованием.

Загрузить свои данныеCSV в формате проекта, без подключения к внешним сервисам+

Один товар и один день — одна строка

Обязательные столбцы: date, sku, sales, price, snap, event. Можно добавить store_id для одного магазина.

Дата: ГГГГ-ММ-ДД. Продажи: целое число от нуля. Цена: больше нуля. SNAP и событие: 0 или 1. Для каждого товара нужен полный одинаковый дневной календарь.

SNAP — календарь продовольственной помощи США; это не скидка магазина. Значения календарных признаков для будущего собственного периода задаются по правилам системы.

Проверка качества на отложенном периоде

Все модели сравниваются на одинаковых датах.

MAE и RMSE — единицы товара. WAPE — сумма абсолютных ошибок относительно суммы продаж; меньше — лучше. Смещение выше нуля означает завышение. Это отдельная историческая проверка, а не оценка ещё не наступившего периода.

Граница прогноза. Модель оценивает наблюдаемые продажи. По нулевым продажам нельзя определить скрытый спрос или отсутствие товара на полке. Точность на одном периоде не гарантирует такой же результат в будущем.
