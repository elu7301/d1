# Глава 3 — приложение и оценка

`app.py` — Flask API и выдача интерфейса.
`service.py` — создание исследования, сохранение вариантов, сравнение и чувствительность.
`test_app.py` — интеграционные проверки с временной SQLite-базой и тесты ML-адаптера.
HTML, JavaScript и CSS лежат в корневых `templates` и `static`, без вложенных папок.

Запуск из корня: `python main.py`, адрес `http://127.0.0.1:5050`.
Приложение сохраняет историю в `data/project.sqlite3`; база исключена из Git.
Документ главы описывает реализацию, проверки и расчётные эксперименты
по пунктам 3.1–3.5 плана ВКР. Числа сценариев относятся к заданным допущениям.
